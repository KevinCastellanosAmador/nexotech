# NexoTech México - Prototipo UX/UI

Prototipo web estático para la actividad UX/UI de NexoTech México. Incluye cinco vistas navegables:

- Inicio
- Mi Ruta Tech
- Detalle de recurso
- Búsqueda y filtros
- Registro

## Cómo abrirlo

Abre `index.html` en el navegador. No requiere instalación ni servidor local.

## Cómo publicarlo

### GitHub Pages

1. Sube todos los archivos de esta carpeta a un repositorio.
2. En GitHub, entra a `Settings > Pages`.
3. Selecciona la rama principal y la carpeta raíz.
4. Guarda los cambios y espera a que GitHub genere el enlace.

### Netlify o Vercel

1. Crea un nuevo proyecto.
2. Arrastra esta carpeta o conecta el repositorio.
3. No configures comando de build.
4. Usa la carpeta raíz como directorio de publicación.

## Estructura

- `index.html`: página de inicio.
- `ruta.html`: experiencia central de Mi Ruta Tech.
- `busqueda.html`: búsqueda con filtros interactivos.
- `detalle.html`: detalle de recurso.
- `registro.html`: formulario de registro simulado.
- `styles.css`: identidad visual y diseño responsive.
- `app.js`: menú móvil, filtros y mensajes de interacción.
- `assets/nexotech-campus-hero.png`: imagen principal del rediseño.
- `assets/nexotech-hero.png`: imagen anterior conservada como respaldo.
